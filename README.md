# 游乐设施日常检验与缺陷闭环平台

基于Vue3、Naive UI、Pinia、Vue Router、TanStack Query、Axios、WebSocket和Vite的独立前端工程。数据默认保存在localStorage，无需后端即可演示。

## 功能

- 检验任务列表、关键词和状态/区域筛选、统计概览。
- 新建检验任务，逐项录入磨损、异响、制动、锁止和安全装置结果。
- 缺陷处置泳道、风险排序、缺陷闭环链（待处置→处置中→待复测→复测通过→已闭环）。
- 状态流转校验、停用隔离、复测与闭环审计。
- JSON记录导出、版本号和完整操作时间线。

## 可恢复的离线同步链

针对早晚班平板断网巡检、回连后与值班室改动撞车的场景，检验任务→缺陷处置→复测→审计已接成一条可恢复同步链：

- **断网打包**：详情页「离线打包」把字段级变更装入同步包，包内保留每个字段的采集时刻、基线值和记录基线版本。
- **按字段合并**：回连后在「同步裁决」页重试，逐字段三方合并——现行值等于包内值则幂等去重，等于基线值则直接落值，被值班室改过的同字段不覆盖，两版并存等值班长确认。
- **放行保护**：设备存在生效放行结论时，旧包中的停用/结果字段一律转入值班长裁决，已复测放行的设备不会被旧记录改回停用。
- **失败重试**：写入失败的批次标记「发送失败」，重试只针对未接收批次（待同步/发送失败），已接收批次不重发；可开启「断网演练」模拟。
- **结论级联**：某批结论一变，来源它的缺陷与依赖它的放行结论随即失效待重核；旧结论作废保留，仍可在详情页判定来源链与审计页查询。
- **判定溯源**：审计页沿设备与批次展开「批次→结论→缺陷→放行」全链，重开页面后仍可找到每条判定的来源。
