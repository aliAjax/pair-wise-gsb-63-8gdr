# 游乐设施日常检验与缺陷闭环平台

基于Vue3、Naive UI、Pinia、Vue Router、TanStack Query、Axios、WebSocket和Vite的独立前端工程。数据默认保存在localStorage，无需后端即可演示。

## 功能

- 检验任务列表、关键词和状态/区域筛选、统计概览。
- 新建检验任务，逐项录入磨损、异响、制动、锁止和安全装置结果。
- 缺陷处置泳道、风险排序、责任人调整和资源冲突提示。
- 状态流转校验、停用隔离、复测与闭环审计。
- JSON记录导出、版本号和完整操作时间线。

## 断网同步链

针对早晚班平板断网巡检、回连后与值班室改动撞车的场景，检验任务、缺陷处置、复测和审计接成可恢复的同步链：

- **断网包**：每次本地保存/流转生成出站批次，包内保留逐字段采集时刻与基线版本（`src/stores/inspection.ts`）。
- **字段级合并**：回连后按字段三路合并——服务端字段自基线未变则应用现场值；两端同值自动收敛；同字段两版不同值则并存，等值班长确认（`src/services/server.ts`）。
- **冲突确认**：同步中心与检验详情页展示现场版/值班室版两版，值班长采纳一版后写回权威端。
- **幂等重试**：写入失败的批次标记待重试，同步只重投未接收批次；服务端按批次号去重，已接收批次重复投递直接回ACK。
- **结论失效重核**：批次结论变更时，相关缺陷处置与放行结论立即失效待重核；已复测放行的任务结论翻转为停用时自动回退待复测。旧结论全部保留可查。
- **判定溯源**：结论、审计均携带设备与批次号，重开页面后可沿设备与批次找回判定来源（模拟权威端独立存储于`gsb63:inspection-server`）。

同步中心提供断网/写入失败模拟开关，以及值班室改动、另一检验员提交的对端模拟，便于复现撞车与合并流程。
